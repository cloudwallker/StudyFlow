# 产品路线与待验证事项

当前实现见[功能矩阵](features/11-status-and-limitations.md)。以下路线尚未实现，不作为现有功能或发布日期承诺。

## 后续产品方向

- 单项任务开始时间与提前提醒，统一 JSON/XLSX、手动计划、重复任务和拖动排程字段。
- CSV/ICS 导入，明确列映射、时区和重复事件规则，继续使用预览与确认流程。
- 可视化备份与恢复，展示兼容版本，恢复前备份并在恢复后校验。
- GitHub CI 与 Windows 长时间验证，分别呈现逻辑测试、Electron 自动化和人工验收结果。

云同步、账号与移动端未实现。应用内不提供 AI 调用、语音识别、自动排程或动态重规划；用户可以在外部生成 JSON/XLSX，再本地检查和导入。

## 人工待验证范围

- 物理锁屏、真实休眠/唤醒、跨午夜实际等待、长时间运行和干净 Windows 机器兼容性。
- 专注小窗多显示器拖动、跨日累计显示及长时间运行。
- 真实音乐选择器、声音听感和音频设备兼容性。
- 真实快捷方式、跨机安装及用户证书签名的最终交付包。

自动化与人工验收的边界见[开发与验证指南](features/09-development-and-verification.md#发布与人工验收边界)。长时间测试步骤见[8 小时测试清单](eight-hour-test-checklist.md)，安装与回退说明见[本地交付指南](local-delivery.md)。
