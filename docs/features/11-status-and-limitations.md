## 使用边界

- 每日打卡与任务整体完成是两种操作。「按日学习」只打卡某天；「全部任务」整体完成任务。依赖以整体完成状态判断。
- 删除任务保留历史和原计划，可恢复；删除项目不删除其任务。有未完成依赖的任务须先解除依赖，当前专注任务先停止。
- 已打卡安排不能直接移动或移除；先撤销当日打卡。归档任务的旧计划仍用于复盘，恢复任务后可继续操作。
- 重复计划按明确起止日期生成，每批最多覆盖 367 天，已有同日同任务跳过；每天最多 500 项、1440 分钟。
- 应用分类只改变展示，不改变白名单提醒和有效学习口径。应用活动时长与学习时长不能直接相加。
- 专注小窗显示工作阶段计时，未扣除 AFK/未知采样；复盘的有效学习时间按原口径计算，两者不能视为同一指标。
- 每日计划提醒默认关闭，仅在应用运行时调度；专注、锁屏和休眠抑制显示。当前是固定时间汇总提醒，没有逐任务开始时刻或提前提醒。
- 崩溃可能丢失最后成功检查点后的数据，历史通常每 30 秒保存。采样不能还原间隔内所有真实输入。
- v7 数据不能直接交给旧版读取；应用回退与数据库恢复分开处理，不能静默覆盖新数据。
- XLSX 只支持规定模板及已说明格式，不接受任意表头、公式、宏、外链、加密表或超限文件。

## 自动化验证范围

源码附带逻辑、SQLite、DOM 和 Windows Electron 验证入口。前端检查涵盖导航、草稿、持续计时、键盘菜单、尺寸/缩放、导入预览及滚动控件可达；具体命令与范围见[开发与验证指南](09-development-and-verification.md)。自动化结果只适用于实际运行的构建与测试场景。

## 验收边界

自动化通过不等于人工实测全部完成。声音实际听感、物理锁屏/休眠/注销、长时间运行和干净 Windows 机器兼容性须按实际记录验收，不能用模拟时钟或代码编译替代。
