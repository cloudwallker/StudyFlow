# 专注计时与番茄钟

## 通用规则

StudyFlow 全局只能有一个开放的计时会话。会话可以绑定未完成任务，也可以是自由专注。开始后不能更换模式或任务；需要先结束当前会话。

计时由主进程持有，不依赖页面是否显示。关闭窗口到托盘后，计时继续。界面区分运行、暂停、等待下一阶段和结束状态。

## 专注小窗

在“本次专注”区域点击“打开专注小窗”，或右键托盘选择同名入口。小窗置顶，可拖动顶部调整位置，以 `时:分:秒` 显示今天累计的专注计时时长，并显示当前任务和运行状态。重复打开复用同一个窗口；“返回主界面”可打开工作台。

计时从点击“开始专注”开始，汇总当天的自由专注和任务专注，支持正计时、定时专注和番茄钟。暂停、等待下一阶段、休息、微休息及异常时钟间隙不累计。它是工作阶段的秒表时长；复盘里的“有效学习时间”还会扣除 AFK 和未知采样，因此两者可能不同。

中途打开小窗会立即显示今天已有时长，开始新一段专注继续累计。关闭小窗或将主界面关闭到托盘不影响记录；小窗本身不启动、暂停或结束专注。按本地日期跨日重新累计，重启恢复已保存的当天时长，停机时间不计入。计时保存沿用原检查点机制，异常退出仍可能丢失最后一次保存后的片段。删除某天历史后，该天小窗累计也相应删除。

## 正计时

正计时从 `00:00` 开始，没有预设上限，直到用户暂停或结束。它适合不确定学习时长的场景。运行中的工作片段仍需和活动采样交叉确认，才会成为有效学习时间。

## 定时专注

定时专注使用“专注设置”中的时长，范围是 1—240 分钟整数。时长保存到数据库，重启后保留。倒计时到零后会话停止并结算。

## 经典番茄钟

默认规则为：

| 参数 | 默认值 | 有效范围 |
| --- | ---: | ---: |
| 工作阶段 | 25 分钟 | 1—240 分钟 |
| 短休息 | 5 分钟 | 1—240 分钟 |
| 长休息 | 15 分钟 | 1—240 分钟 |
| 长休息间隔 | 每 4 个工作番茄 | 1—100 个 |

完成工作阶段后进入短休息；达到长休息间隔时进入长休息。休息结束后回到工作阶段。每个阶段结束时都会停在“等待确认”，必须点击“开始下一阶段”，不会在无人操作时自动累计下一阶段。

只有完成的工作阶段增加每日“完成番茄”数量。休息阶段、被中途结束的工作阶段和跨日片段的非最终部分不算完成番茄。

点击“保存设置”或成功开始计时后，常用模式、番茄工作/短休息/长休息时长、长休息轮数和 AFK 阈值会保存到本地数据库。重启后恢复这些偏好，不自动恢复未结束的计时。

等待下一阶段时，可在“下一阶段”中填写 1—240 分钟，再点击“开始下一阶段”。此次调整只影响即将开始的一段，不改写已保存的默认时长。

## 长专注＋微休息

选择“番茄钟”，展开“本次计时设置”，勾选“长专注＋微休息模式”。这是可选模式，不改写经典番茄配置。

| 设置 | 默认值 | 范围 |
| --- | --- | --- |
| 本轮总时长 | 60 分钟 | 1—240 分钟整数 |
| 启用微休息 | 关闭 | 独立勾选 |
| 微休息前的工作间隔 | 随机 2—3 分钟 | 最小/最大各 1—240 分钟；相同则固定 |
| 微休息时长 | 10 秒 | 1—600 秒整数 |
| 轮后长休息 | 10 分钟 | 1—240 分钟整数 |

微休息自动开始、结束和继续工作。本轮总时长包含微休息，到点即进入长休息；若正在微休息，会精确裁剪。长休息结束等待手动开始下一轮。手动暂停冻结本轮和微休息两层倒计时，继续时保留剩余工作间隔或休息秒数。锁屏、休眠和异常间隙沿用暂停保护；“准时结束”以未暂停且时钟有效的运行时间为准。

界面显示本轮剩余时间及距离微休息/微休息剩余秒数。本次统计、每日汇总和时间线单列微休息；每日“休息”总数包含微休息，二者不重复相加。微休息不计入有效学习，也不产生分心提醒；整轮结束仍只增加一个完成番茄。

打开“番茄钟声音引导”后，可分别选择专注开始、微休息开始、微休息结束、长休息开始、整轮完成和长休息结束的音色、音量与试听。高音单铃用于开始/继续，低音单铃用于休息开始，上行旋律用于整轮完成，三声柔和提示用于长休息结束。整轮完成时优先庆祝音，长休息开始音不叠加；该声音可单独试听。所有音色均本地程序合成，无素材下载。

微休息开启时替代原随机提示音；关闭微休息时长专注仍可使用随机提示。经典番茄使用原全局音量，长专注使用独立事件音量；模式切换不会让隐藏音量覆盖可见配置。暂停或停止取消播放，不续播被截断的铃声，不补播迟到的一串提示。设置保存后重启保留，不恢复旧计时。

相关验证命令及人工待验范围见[开发与验证指南](09-development-and-verification.md)。

## 经典番茄钟声音引导

在“专注设置”打开“番茄钟声音引导”（默认关闭），可配置：

- 随机提示音最小、最大间隔，各为 1—240 分钟，默认 3—5 分钟。每次重新随机抽取；两者相同则按固定间隔提醒。间隔超过本段工作时长时，本段不会播放随机轻响。
- 柔和、清铃、木音三种合成音色，以及 0—100 音量（默认 40，0 静音）。实际响度还受 Windows 和音频设备音量影响。
- 三个试听按钮分别播放工作中轻响、工作完成庆祝音、休息完成连续短音；试听采用当前输入，不自动保存。

只有运行中的番茄工作阶段播放随机轻响；工作完成播放上行庆祝音，休息完成播放三段柔和短音一次，然后等待手动开始下一阶段。休息、暂停、停止、锁屏时不继续播放随机提示；暂停恢复或开始新工作阶段会重新计算间隔，不补播遗漏提示。停止和系统中断会取消尚未播放的阶段提示。声音失败会显示错误，不影响计时，也不快速重试。

声音偏好随“保存设置”或开始计时存入本地，重启保留。声音由主进程管理短时 Windows 播放进程，关闭页面到托盘不依赖页面定时器。普通倒计时、正计时不启用这一声音引导。已有分心提醒的 60 秒冷却独立保留。

声音听感与设备兼容性需要在目标 Windows 机器上验证，范围见[功能与限制](11-status-and-limitations.md#验收边界)。

## 暂停、继续和结束

- “暂停计时”先结算到当前时刻，再进入暂停状态；暂停时间单独记录。
- “继续计时”从新的时间锚点恢复，不把暂停间隔补算为工作。
- 在番茄“等待确认”状态点击继续，会开始策略指定的下一阶段。
- “结束本次专注”结算已确认片段；重复结束不会重复累计。

暂停、等待和休息期间不累计有效学习，也不产生分心提醒。开启全天独立记录后，活动轨道仍继续采集。

## 时钟与异常间隙

计时长度使用单调时钟，墙钟只用于日期和展示。这样可以避免用户调整系统时间直接改变已计时长。

- 两次推进间隔超过 90 秒时，该段记为未知并自动暂停，用户需要手动继续。
- 墙钟相对单调时钟偏差超过 2 秒时，该段记为未知；无法建立可信结束时间的片段不会伪造墙钟区间。
- 小幅墙钟抖动沿用原时间映射，避免产生重叠或空洞。
- 单调时钟回退属于无效状态，会报错而不是继续累计。

跨午夜片段按记录时的 UTC offset 拆分到对应本地日期，仅最终片段保留阶段完成标记。
