# 安装、启动与界面

## 可用版本

当前应用版本是 `0.5.0-local`。完成依赖安装后的开发运行命令是：

```powershell
npm run start:desktop
```

它需要 Windows x64、Node 24、已安装的 npm 依赖和 Electron 缓存。首次准备开发环境可依次运行：

```powershell
npm ci
npm run install:electron
npm run start:desktop
```

`release/` 和 `dist/` 是本机构建产物，不随 Git 克隆取得。执行 `npm run package:desktop`
后，正常便携包位置写入 `dist/desktop-package-path.txt`；保留整个包目录，再运行其中的
`StudyFlow.exe` 或 `install-studyflow.cmd`。安装升级流程见[本地安装说明](../local-delivery.md)，
构建与验证方法见[开发指南](09-development-and-verification.md)。界面操作和响应式布局见
[界面使用指南](12-frontend-layout.md)。

## 主界面结构

- 左侧导航切换学习工作台、活动与复盘、设置。
- 页面顶部显示任务统计，并提供添加任务和导入计划入口。
- 工作台包含按日学习、全部任务、项目筛选，以及任务、项目与分类管理。
- 工作台右侧是本次专注及计时参数，可开始、暂停、继续、结束或打开专注小窗。
- 活动与复盘页提供日期读取、汇总、双轨时间线、应用分类和计划/实际对比。
- 设置页包含白名单、活动记录、每日计划提醒及按日期删除历史入口。

## 首次使用

1. 在左侧输入项目名称并创建项目；不需要分类时可以跳过。
2. 输入任务名称，选择项目并填写预计分钟数，然后添加任务。
3. 选择计时模式与本次任务。任务下拉框包含所有未完成任务，也可以选择自由专注。
4. 设置允许使用的应用。每行填写一个完整可执行文件名，例如 `Code.exe`。
5. 点击“保存设置”，再开始专注。

## 窗口和托盘

应用正常创建托盘图标时，关闭主窗口只会隐藏窗口，后台计时和采样继续。托盘菜单提供：

- 打开 StudyFlow；
- 结束当前专注；
- 退出 StudyFlow。

双击托盘图标也会重新打开窗口。应用只允许一个实例；再次启动会唤醒已有窗口。若托盘创建失败，关闭最后一个窗口会退出应用。

## 界面刷新和保存

主任务与计时区域每秒读取一次主进程状态。任务、设置和计时按钮在写操作进行时临时禁用，避免重复提交。

每日区域独立读取。修改日期后必须点击“读取日期 / 刷新”；计划与复盘会保存到“当前读取 / 保存日期”。若日期输入已改变但尚未读取，保存会被拒绝。重新读取会覆盖未保存编辑，界面会先询问是否继续。
