# 界面使用指南

本指南描述 `0.5.0-local` 当前界面，更新日期为 2026-10-02。前端调整保留原有计时、任务、数据与后台行为。

[English overview](../../README.md) · [中文首页](../../README_ZH.md)

## 学习工作台

左侧导航切换“学习工作台”“活动与复盘”和“设置”，项目列表用于筛选任务。顶部概况显示全部待办、整体已完成和累计任务专注；这些是总体数据，不随日历日期变成当天统计。

任务区默认显示“按日学习”：选择本周日期，或点击“展开月历”查看整月；“今天”返回当天，“计划首日”跳到当前项目的第一天。往日未完成安排列在下方，可补打卡。切换“全部任务”查看整体任务列表。

“按日学习”的打卡仅影响该日；“全部任务”的完成标记影响整个任务。重复练习可以在不同日期独立打卡，不能把两种完成状态当成同一操作。

任务行保留“开始专注”和完成/打卡按钮。点击“更多”打开编辑菜单；全部任务还提供上移、下移。菜单支持键盘和触摸，无需悬停；Escape 关闭并回到“更多”。后台更新保留对应日期菜单的展开状态和焦点，排序后焦点回到该任务的“更多”。编辑任务会聚焦原有编辑器。

“进入专注模式”收起次要界面，突出任务与计时；再次点击可退出。切换到设置、复盘或打开录入时也会退出该模式。

## 本次专注

右侧先选择计时模式与任务，再点击“开始专注”。任务旁的开始按钮直接绑定对应任务；自由专注不绑定任务。暂停、继续、结束和等待下一阶段的状态显示在同一区域。

“本次计时设置”集中提供番茄参数、长专注、微休息和空闲阈值。更多说明见[计时与番茄钟](03-timers-and-pomodoro.md)。

打开其他页面时，正在进行的专注保留；页面上方的运行提示可返回工作台。关闭主窗口到托盘后由后台继续计时。专注小窗置顶显示当天工作阶段累计秒表时间，不改变当前会话。

## 添加与导入

顶部“添加任务”打开录入区并聚焦标题；“导入计划”打开导入区并聚焦文件选择。

导入分为三个步骤：

1. **选择内容**：选择 JSON/XLSX 文件，或直接粘贴 JSON。文件最大 1 MiB，可从同一区域下载示例模板。
2. **检查预览与差异**：核对任务数、天数、日期范围、分钟数和未安排日期的任务；处理同名项目与任务更新选择，检查合并或明确整日替换的变更。
3. **确认保存**：校验通过后点击确认。修改来源、日期或冲突选择后，须重新预览；取消不会写入。

导入优先使用文件中的明确日期；没有日期时可选择第 1 天日期并按标题中的天数推导。界面中的格式说明提供 JSON 字段和 Excel 表头规则。

## 设置

设置页按专注默认值、声音、应用与活动记录、每日计划提醒、数据管理分组。分组导航跳到对应内容；输入完成后点击该功能的保存按钮。

每日计划提醒独立保存，可在专注期间修改，不覆盖未保存的计时或白名单草稿。计时、白名单和活动记录等设置在运行会话中不可修改，需要先结束专注。

数据管理中的历史删除不可撤销。删除前核对日期，结束专注，并关闭、保存全天记录。任务累计和每日计划快照保留；详见[备份与恢复](07-data-backup-and-recovery.md)。

## 活动与复盘

选择日期后点击“读取日期 / 刷新”，再查看数据或保存编辑。保存始终针对页面显示的“当前读取 / 保存日期”，只改日期输入不会自动切换上下文。

较宽窗口中，时间线与复盘编辑分别排列；较窄窗口按阅读顺序堆叠。学习轨道与应用轨道相互独立，重叠时间不能相加。有效学习时间已排除 AFK、未知和休息。

勾选任务并填写分钟数可保存当天计划快照；复盘记录“完成了什么”“遇到什么”“明天调整”。切换主页面保留草稿；重新读取会提示丢弃未保存内容。任务或计划变化后需重新读取计划，已有复盘草稿仍可保存。

本轮前端已通过自动化交互与布局检查，人工验收跳过。真实锁屏/休眠、长时间运行和跨机器兼容性仍需另行验证。
