# 每日计划与计划/实际对比

## 读取日期

每日区域默认填入系统当天日期，但保存前以“当前读取 / 保存日期”为准。改变日期输入后点击“读取日期 / 刷新”，页面才会切换上下文。这样可以避免用户查看一天后误把内容保存到另一天。

## 创建计划快照

页面列出当前数据库中的任务。勾选要安排的任务，为每项填写当天分配分钟，再点击“保存当天计划快照”。

规则如下：

- 每项分配为 0—1440 分钟整数；
- 一个计划最多 500 个任务；
- 同一任务不能重复；
- 保存时任务必须存在；
- 不勾选任何任务也可以保存，表示明确的空计划；
- 重新保存同一天会整体替换旧快照。

快照保存任务 ID、当时的任务标题、分配分钟和保存时间。任务以后改名或修改预计时间时，未重新保存的历史计划标题与分钟保持不变。当前支持任务编辑和明确的导入更新；重新保存/导入更新该日期时会记录新快照。每日最多 500 项、1440 分钟；已打卡任务不能直接从计划移除。

## 实际时间

“实际”只统计所选日期内的有效学习片段，不使用任务的全部历史累计。因此：

- 跨午夜会话只计入当天部分；
- AFK、未知、暂停、等待和番茄休息不计入实际；
- 未安排但当天投入过的任务会作为“无计划实际投入”出现；
- 自由专注单独出现，不强行归属任务；
- M2 或更早只有累计值、没有每日片段的旧时间不会伪造为某天实际。

## 对比字段

| 字段 | 计算方式 |
| --- | --- |
| 计划分钟 | 快照中的分配分钟 |
| 实际分钟 | 当天有效学习毫秒换算 |
| 差值 | 实际 − 计划；负数表示低于计划，正数表示超出计划 |
| 时间完成率 | 实际 ÷ 计划，可超过 100% |
| 当前任务状态 | 任务当前是否完成；自由专注单独标明 |

计划为零或没有计划时，时间完成率显示“无计划基准”，不会除以零。任务的完成勾选状态和时间完成率是两个不同维度：任务可以勾选完成但投入时间低于计划，也可以尚未勾选却已超过计划。

## 删除和保留规则

删除某天历史后，该日实际时间与复盘被清除，但计划快照继续保留，便于知道原计划是什么。若再次产生该日历史，比较会自动使用保留的计划。
