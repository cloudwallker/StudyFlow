# 后台生命周期、隐私与安全

## 生命周期

- 主进程持有唯一计时器和采集器，页面隐藏不会终止会话。
- 有托盘时，关闭窗口进入托盘；托盘可以重新打开、结束专注或退出。
- 锁屏和系统休眠事件会中断当前运行片段并暂停计时。
- 从锁屏或休眠返回后不会自动继续，用户必须点击继续。
- Windows 注销查询阶段会停止并结算会话；会话结束阶段释放数据库、采集子进程、提醒和托盘。
- 普通退出会先结算；若保存失败则取消退出并显示错误。
- 只允许一个实例，第二次启动会聚焦已有窗口。

目前锁屏、休眠和注销的自动化使用事件注入验证；真实系统锁屏/休眠仍是发布验收项。强制结束进程、断电或操作系统不给予退出时间时，最后一个检查点之后的数据可能丢失。

## 本地优先与网络边界

独立桌面版的页面只加载本地 HTML、CSS 和脚本。内容安全策略默认拒绝所有资源，只允许自身脚本、样式及本地/data 图片。主进程还取消 HTTP、HTTPS、WebSocket 请求，拒绝页面权限请求、外部窗口和页面导航。

渲染器启用 Electron sandbox 和 context isolation，关闭 Node integration；仅通过预加载层暴露受限命令。主进程校验 IPC 必须来自当前窗口主 frame 和准确本地页面 URL。

正常运行不访问 Super Productivity Plugin API、ActivityWatch REST API、云端、LLM 或遥测服务。

## 保存的数据

默认保存项目、任务、设置、计时会话、计时片段、每日计划和复盘。应用活动记录默认关闭。

开启“记录应用活动”后，只在计时会话内保存应用可执行文件名和活动/AFK/未知区间。不会保存：

- 窗口标题；
- 浏览器 URL 或历史；
- 文件路径；
- 键盘输入或鼠标内容；
- 屏幕内容；
- Super Productivity 或 ActivityWatch 用户数据库。

即时白名单提醒即使在历史记录关闭时仍需要读取当前应用，但不会因此把应用名写入历史表。应用分类、每日计划和复盘完全保存在本机。

## 日志和错误

主进程不会把真实任务内容、窗口标题、路径或原始活动数据写入产品日志。IPC 原生错误带系统错误码时，界面只显示通用保存失败信息；可安全展示的领域校验错误才原样返回。

## 行为边界

StudyFlow 只提供温和提醒。它不会关闭其他应用、结束进程、锁屏、屏蔽输入、修改 hosts、提升管理员权限或绕过系统限制。
