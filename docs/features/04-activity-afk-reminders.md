# 应用采集、AFK 与提醒

## 每日计划提醒

在「设置 → 每日计划提醒」启用并选择每天的本地时间，单独点击「保存提醒」。默认关闭，默认时间 09:00；可以在专注期间保存，不改变计时偏好。

到达时间后，提醒汇总今天未完成、未归档且未当日打卡的计划，显示任务与分配时长。没有待做计划则不提醒；当天晚开应用会补今天一次，不追补往日计划。主进程约每 10 秒检查，关闭到托盘仍运行，退出后停止。

弹窗支持「查看今天」「10 分钟后」「今日忽略」。关闭或查看后不自动重复提醒，只有主动选择稍后才会追加；稍后时间和去重记录跨重启保存。当天修改提醒时刻不会重置已处理记录。跨午夜的稍后作废，新一天按新一天的设置判断。

专注会话未结束、锁屏或休眠期间延后显示，恢复后重新检查。已显示的计划提醒在这些场景下关闭；尚未显示就被取消的提醒释放占用，恢复后可重新判断。真实显示失败不自动重试，当次运行的设置状态会显示失败；数据库读取或记录失败至少等待 60 秒再试。

这是每日计划汇总提醒，不是每项任务的开始时间提醒。现有计划还没有开始时刻字段。验证方法和人工待验范围见[开发与验证指南](09-development-and-verification.md)。

## Windows 前台应用采集

独立桌面版启动自带的 `StudyFlowSampler.exe` 子进程。主进程通过固定的 stdin/stdout 协议请求样本，得到：

- 当前前台应用的可执行文件名；
- 距离最后一次用户输入的毫秒数；
- `ok` 或 `unknown` 状态。

采集不会读取或返回窗口标题、URL、文件路径、按键内容或鼠标内容。被 Windows 权限拒绝、窗口无有效进程、返回内容非法或子进程失败时，结果为未知，不提升管理员权限。

采样请求串行执行，不会重叠。运行中的会话通常每 3 秒尝试一次；子进程单次响应超时为 4 秒。取消、停止或切换会话后，迟到结果不会写入新会话。

## AFK 判断

空闲阈值默认 5 分钟，可设置为 1—240 分钟整数。点击保存设置或开始计时后跨重启保存，全天记录沿用该阈值。

当 Windows 报告的最后输入时间达到阈值时，StudyFlow 会把当前连续活动尾段从最后输入时刻开始回溯标记为 AFK。用户返回后，根据最新 idle 值把返回前后分别记为 AFK 和活动。这意味着界面上的有效学习时间可能在阈值首次达到时向下修正。

采样只能反映被观察到的状态，无法还原两次采样之间的每一次输入。超过 90 秒的采样间隙、墙钟异常、采样超时或未知样本均记为未知，不沿用上一个应用，也不计为有效学习。

## 有效学习口径

“全天独立活动记录”默认关闭。开启并保存后，无需启动专注，主进程也会持续记录应用、AFK 和未知区间；关闭到托盘继续，退出应用后停止，重启恢复开关但不补算停机时间。每日应用时间线合并全天记录和会话记录，重叠区间只展示、汇总一次。全天活动不增加任务用时。

独立记录每约 30 秒保存，关闭开关与普通退出前也保存。锁屏、休眠和无法采样的间隔标为未知。删除历史前须关闭并保存全天记录，避免未提交尾段再次写回。

成功提交后释放超出“AFK 阈值 + 90 秒余量”的旧区间；专注累计汇总保留，详细历史留在 SQLite。保存失败时不释放未保存数据，显示错误并保留重试能力，因此持续磁盘故障时内存仍可能增长。

有效学习时间是“工作计时片段”和“已确认 active 活动区间”的交集。两个轨道的重叠只计算一次。

- active + 工作阶段：计入有效学习；
- AFK + 工作阶段：计入 AFK，不计学习；
- unknown + 工作阶段：计入未知，不计学习；
- 休息、暂停、等待：不计学习，即使用户仍在操作电脑。

## 白名单

白名单每行一个完整应用名，最多 100 项。保存时会去除首尾空格、统一为小写并去重，匹配时忽略大小写和首尾空格，但仍是完整名称精确匹配。例如 `Code.exe` 与 `code.exe` 等价，`Code` 不匹配 `Code.exe`。

白名单为空时，所有可识别的活动应用都属于提醒对象。白名单只控制提醒，不代表应用一定用于学习，也不会自动成为历史分类。

专注运行时不能修改全局时长、白名单或活动记录开关，需要先结束会话。

## 居中提醒

工作阶段检测到 active 且应用不在白名单时，会显示 StudyFlow 自有的居中置顶提醒。提醒窗口：

- 位于鼠标所在显示器的可用工作区中央；
- 不抢夺键盘焦点；
- 显示当前应用并提示返回学习任务；
- 8 秒后自动关闭；
- 使用 60 秒全局冷却，切换到另一个非白名单应用也不会绕过冷却。

回到白名单、进入 AFK/未知、进入休息、暂停、停止、锁屏或退出时会撤回现有提醒。通知窗口创建失败只标记提醒失败，不快速重试刷屏，也不影响计时结算。
