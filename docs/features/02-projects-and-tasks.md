# 项目与任务

## 项目

项目用于筛选和归类任务。项目名称会去除首尾空格，不能为空，最多 80 个字符，不接受控制字符。项目创建后立即写入本地 SQLite。

当前界面支持创建和选择项目；在「任务、项目与分类管理」中改名、上下排序或删除。删除项目把所属任务移至未分配，不删除任务和历史。选择“全部任务”显示所有任务；选择具体项目只改变列表筛选。

## 任务

新建任务包含以下字段：

| 字段 | 规则 |
| --- | --- |
| 标题 | 必填，去除首尾空格，最多 200 字符，不接受控制字符 |
| 项目 | 可为空；非空时必须指向已存在项目 |
| 预计时间 | 1—240 分钟整数 |
| 完成状态 | 新任务默认为未完成 |
| 已用时间 | 新任务默认为 0，由有效学习检查点累计 |

任务列表显示标题、项目、预计时间和预计剩余时间。剩余时间为 `预计时间 − 已记录任务专注`，最低显示 0，不显示负数。

## 完成与重新打开

勾选任务会把它标为完成；取消勾选可重新打开。完成任务不再显示任务行上的“专注”按钮，也不会出现在专注任务下拉框中。

若正在计时的任务被标记完成，当前会话会立即停止并结算，界面显示“任务已完成，本次专注已结束”。

点击任务旁「编辑」可修改标题、预计时间、项目、标签和前置依赖。标签最多 20 个，每个最多 40 字符；前置依赖最多 100 个，拒绝循环，前置任务未整体完成时不能开始当前任务。

删除任务采用可恢复归档，在管理区恢复；累计时长、原计划和历史保留。有未完成任务依赖它时需先解除依赖，正在专注的任务需先停止。搜索可匹配标题、项目或标签，也可按标签/状态筛选；「全部任务」支持拖动及上移/下移。

「按日学习」的打卡只影响该日期，同一任务安排多天时各日独立。「全部任务」中的完成操作才是整体任务完成。打卡不补造实际学习时长；旧版本迁入的完成记录没有伪造的打卡时刻。

编辑器可按起止日期生成单次或每 1/7/14/30 天重复安排（每批最多覆盖 367 天），已有同日同任务跳过。日期移动可通过编辑器或将任务拖到日历格完成；已打卡安排须先撤销打卡。

## 任务专注累计

绑定任务的会话只累计已确认的有效学习时间。以下时间不会增加任务的 `spentMs`：

- 暂停时间；
- 番茄休息时间；
- 等待手动开始下一阶段的时间；
- AFK 时间；
- 采样未知或长间隙时间；
- 自由专注时间。

历史检查点与任务累计在一个 SQLite 事务内提交。AFK 回溯修正可能让新检查点中的有效时间变少，任务累计会按新旧差额同步修正，不会重复增加。

删除某天历史不会减少任务累计。这是明确的数据口径：历史可以清除，但已经结算到任务的总时间继续保留。
