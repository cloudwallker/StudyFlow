# StudyFlow 当前功能文档

本文档集描述 `0.5.0-local` 的实际功能，数据库为 schema v7。内容以当前源码为依据，未来路线不计入已实现能力；自动化与人工验收边界分别说明。

## 产品定位与当前状态

StudyFlow 是面向 Windows 的个人、本地优先学习与专注应用。独立桌面版拥有自己的项目、任务、计时、前台应用采集、提醒、历史、计划和复盘能力，正常运行不依赖 Super Productivity 或 ActivityWatch。仓库还保留一套旧 Phase 0 插件原型，用于兼容构建与回归验证。

当前版本提供计时、AFK、历史、每日复盘、计划对比、任务管理、JSON/XLSX 文件与粘贴导入、导入差异预览、每日计划提醒、专注小窗和本地声音。

源码仓库不包含便携包或缓存。按[开发与构建指南](09-development-and-verification.md)生成完整 Windows 便携目录，再按[安装说明](../local-delivery.md)运行或安装；保留整个包目录。

## 最短使用流程

1. 创建项目（可选），再创建任务并填写预计分钟数；也可导入 JSON/XLSX 文件或粘贴 JSON，预览后确认写入。
2. 在右侧选择计时模式和任务；按需设置白名单、番茄参数及 AFK 阈值。
3. 点击“开始专注”。使用任务旁的“专注”会直接绑定该任务；“自由专注”不计入任何任务累计。
4. 暂停、继续或结束会话。番茄阶段结束后，需要手动开始下一阶段。
5. 按需打开置顶专注小窗；在设置中启用每日计划提醒，选择提醒时间。
6. 打开“活动与复盘”，读取日期，查看时间线和汇总，填写计划或复盘。

## 统一术语

- **会话**：一次从开始到最终停止的计时过程。
- **经过时间**：会话墙钟上经历的全部时间，包括工作、休息、暂停、等待和未知区间。
- **有效学习时间**：工作片段与已确认活动区间的交集；任务累计和每日实际使用此口径。
- **AFK**：达到空闲阈值后确认的无人操作时间，不计为有效学习。
- **未知时间**：采样失败、长采样间隙或墙钟异常等无法可信归类的时间，不计为有效学习。
- **计划快照**：某一天显式保存的任务标题、任务 ID 和分配分钟数，不随任务后续变化自动改写。
