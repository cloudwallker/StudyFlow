# StudyFlow 测试版：另一台电脑 8 小时测试

适用于 0.3.0-test.1，Windows 10/11 x64。本文件是操作清单，不是通过报告。

## 开始前（不计入 8 小时）

1. 复制整个 ZIP 到本地磁盘并解压。不要只复制 exe，不要在压缩包内启动。
2. 双击 `StudyFlow-Test.exe`。无需安装 Node、Python、Super Productivity 或 ActivityWatch；测试时后两者应退出。
3. 本包未签名。如被系统拦截，先核对来源及 SHA-256；不要关闭杀毒或系统防护。记录提示，不能启动就作为兼容性问题反馈。
4. 使用虚构任务。本测试版数据独立保存在 `%APPDATA%\StudyFlow-Test`，不会自动读取正式版 StudyFlow 数据。正常退出后复制该目录可自行备份，诊断导出不包含它。
5. 接通电源，保持联网与否均可。关闭自动睡眠，仅在计划环节手动休眠，测试后恢复原设置。
6. 检查顶部“运行监测”为运行中、“日志写入失败”为 0。点击“诊断自检”，再试一次“导出诊断包”。自检不是应用实际故障。
7. 记录开始时间、系统版本、显示器数量/缩放与包版本。无需提供用户名、机器名、账号。

## 8 小时安排

| 相对时间 | 操作 | 验收观察 |
| --- | --- | --- |
| 00:00—00:30 | 创建虚构项目/任务；导入 `测试文件/正常计划.json`；重复导入；取消预览；导入 `错误计划.json` | 预览取消和错误输入不写入；重复导入不重复创建；查看文件中计划对应日期 |
| 00:30—01:30 | 定时专注；按采样显示的应用名设置白名单，切换允许/不允许应用 | 允许和未知应用不提醒；非白名单可见居中提醒；60 秒内不重复；停止后不再提醒 |
| 01:30—02:30 | 正计时、暂停/继续、短周期番茄钟 | 暂停不累计；番茄阶段手动确认；停止不重复累计 |
| 02:30—04:30 | 关闭到托盘，正常学习工作；每小时打开确认一次 | 后台计时/采集继续，界面重开状态一致，无明显卡顿 |
| 04:30—05:00 | 不操作超过 AFK 阈值（默认 5 分钟）；随后分别锁屏、解锁；休眠、唤醒 | 空闲扣除合理；锁屏/休眠暂停，返回手动继续；不把间隙补成有效学习 |
| 05:00—07:00 | 保存设置启用全天活动记录，继续工作，部分时段停止专注 | 无专注时仍有活动轨道；与学习时间不相加；定期刷新每日数据 |
| 07:00—07:30 | 结束计时、托盘退出、重新启动；重复导入同一 JSON | 任务/计划/历史保留；不自动恢复运行会话；不重复导入或计时 |
| 07:30—08:00 | 保存复盘、核对计划/实际、导出最终诊断 ZIP；托盘退出 | 报告可导出；无 StudyFlow-Test、StudyFlowSampler、StudyFlowWatchdog 遗留进程（监测器最多延迟约 5 秒退出） |

这是包含休眠/重启的 8 小时综合测试，不代表连续在线 8 小时。无人值守只覆盖运行稳定性，不能验证提醒可见与交互。不要为了测试强制关机、修改系统时间、删除数据库或结束其他应用。

## 遇到问题

- 点击顶部“记录一个问题”，选择类别；在 `问题记录表.tsv` 填写时间、操作、预期、实际结果。标记只记类别，不收集文本内容。
- 界面不能操作时，手工记下时间。若仍能从托盘正常退出，先正常退出；确实卡死再通过任务管理器结束本测试版，重新启动导出报告。
- 应用启动失败无法导出时，保留 `%APPDATA%\StudyFlow-Test\diagnostics` 目录，可仅压缩该目录反馈。不要发送整个数据目录或数据库。
- 导出报告保留最近最多 8 次运行的概要与受限日志。请不要反复重启数十次覆盖证据。导出到自己选定位置的 ZIP 由你管理，不自动清理。
- 日志写入失败、监测不可用、连续采集失败、保存失败均应记录；没有错误日志不等于功能全部通过。

## 完成标准

无意外崩溃/持续无响应、无数据库损坏；已确认保存的数据重启后保留；不重复累计；托盘工作正常；退出清理正常。资源性能由日志趋势和人工体验分析，测试版不凭单个阈值自动宣告通过。

报告按 runId 区分每次启动；主报告显示当前运行时长（含休眠），其他运行概要随包保留。CPU/内存为 Electron 进程合计，不包含原生采集器和监测器。突然断电无法保证留下最后瞬间错误，心跳间隙不能单独判断是卡死还是系统休眠。

请返回最终诊断 ZIP 和填写后的问题记录表；截图仅在需要且确认不含隐私时自愿提供。另一台电脑实际测试结果才是跨机和 8 小时验收证据。
